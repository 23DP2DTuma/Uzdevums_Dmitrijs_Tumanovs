User Guide

  • 1# "Start"

    To start the Car Management System, open your terminal or command prompt, navigate to the folder containing the program files, and run the command java MasinuSistema. The system will try to load existing data from the masinas.csv file or start with an empty list if the file doesn't exist.

  • 2# "Main Menu"

    When the system starts, you'll see the main menu with seven options. To select an option, simply type the corresponding number (1-7) and press Enter.

  • 3# "Adding a Car"

    To add a new car, select option 1 from the main menu. You'll need to enter the car's details when prompted: first the make (letters only), then the model (letters and numbers), color (letters only), year (between 1850 and 2025), and price (a positive number). After entering all information, the system will automatically assign an ID to the car and add it to the list.

  • 4# "Viewing Cars"

    To view all cars in the system, select option 2 from the main menu. If there are cars in the system, they will be displayed in a table format sorted by ID in ascending order. If there are no cars, you'll see a message indicating that the list is empty.

  • 5# "Sorting Cars"

    To sort the cars, select option 3 from the main menu. You'll be prompted to choose a sorting method by entering a number from 1 to 8. You can sort by ID (ascending or descending), price (ascending or descending), year (ascending or descending), make (alphabetically), or model (alphabetically). After choosing a sorting method, the system will display the sorted list of cars.

  • 6# "Filtering Cars"

    To filter cars based on specific criteria, select option 4 from the main menu. You'll be prompted to choose a filtering method by entering a number from 1 to 5. You can filter by price range, make, color, year range, or ID range. Depending on your choice, you'll need to enter additional criteria such as minimum and maximum values for ranges or exact names for make and color. The system will then display only the cars that match your criteria.

  • 7# "Editing a Car"

    To edit an existing car, select option 5 from the main menu. The system will display all cars and ask you to enter the ID of the car you want to edit. After entering the ID, you'll see the current information and be prompted to enter new values. For text fields (make, model, color), simply press Enter to keep the existing value or type a new one. For numeric fields (year, price), enter 0 to keep the existing value or enter a new number. The system will update the car with your changes.

  • 8# "Deleting a Car"

    To delete a car, select option 6 from the main menu. The system will display all cars and ask you to enter the ID of the car you want to delete. After entering the ID, you'll see the car's information and be asked to confirm the deletion. Type "j" to confirm or "n" to cancel. If confirmed, the car will be removed from the list.

  • 9# "Saving and Exiting"

    To save your changes and exit the program, select option 7 from the main menu. The system will save all car data to the masinas.csv file and terminate. Note that changes are only saved when you use this option – if you close the program any other way, your changes might not be saved.

  • 10# "Data Validation"

    The system applies validation rules to ensure data integrity. Make and color must contain only letters, model can contain letters and numbers, year must be between 1850 and 2025, and price must be a positive number. If you enter invalid data, the system will prompt you to enter it again.
